# cgi-cat-girl-intelligence
CGI (Cat Girl Intelligence) is a little substitution-based chatbot that answers everything with meow.

Project description (specification) and usage help inside Python file.
While running the program, type \help for help.

## PROJECT STATE
Can handle reversing subject and be, cannot handle reversing verb. It also cannot handle LIKE TO VERB structures (it handles them wrong).
Which means only the first 2 sentence structures have been semi-implemented.

## Example

```
=== CGI (Cat Girl Intelligence) prototype v0.1.1 ===
Type '\help' for more information.
> How are you?
I am meowly.
> Why is that?
That is because of meowing.
> What does that mean?
That mean meow.
> 'Mean'?
Meow?
> I am asking that.
Meow.
> Anyway...
Meow.
> How are we going to build that project we were talking about?
We are going to build that project we were talking about meowly.
> Why?
Because of meowing?
> Exactly.
Meow.
> What are you thinking about doing in the summer?
I am thinking about doing meow in the summer.
> Why are you thinking about doing that in the summer?
I am thinking about doing that in the summer because of meowing.
> How are you achieving that?
I am achieving that meowly.
> How are you able to do it?
I am able to do it meowly.
```
